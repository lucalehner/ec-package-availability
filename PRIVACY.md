## 2. Summary

## 3. What the extension does

The extension runs only on pages of `https://endpointcentral.manageengine.eu/`. When the Endpoint Central MSP console loads its software package list, the extension:

- shows the existing package attribute `IS_FOR_ALL_CUSTOMERS` as an "Availability" column, and
- adjusts search, sort and paging requests for that column so the list can be filtered and sorted by it.

All of this happens **locally in your browser**, inside your existing, authenticated session with Endpoint Central. The extension makes no network requests of its own.

## 4. Data we do not collect

The extension does not collect, store or transmit:

- personal information (names, e-mail addresses, IDs)
- authentication data (passwords, tokens, cookies)
- browsing history or website content
- usage statistics, analytics or telemetry

The data the extension processes (the package list) is already sent to your browser by Endpoint Central. It is processed only in memory, only to change how it is displayed, and is discarded when you leave or reload the page. No data is sent to the publisher or any third party.

## 5. Storage, cookies, tracking

The extension uses no cookies, no local storage, no analytics and no tracking services, and it loads no remote code.

## 6. Permissions

The extension needs no Chrome API permissions. It only declares a content script for `endpointcentral.manageengine.eu`, which is needed to display the additional information on that site.
